# 📝 MCQ Generator AI

An AI-powered Multiple Choice Question Generator using Python, Streamlit, and Hugging Face.

## 🚀 Live Demo

👉 https://mcq-generator-ai.streamlit.app/

## ✨ Features

- Generate MCQs using AI
- Select topic
- Select number of questions
- Select difficulty level
- Choose options for each question
- Check correct and incorrect answers
- View explanations
- User-friendly Streamlit interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Hugging Face
- Hugging Face Inference API

## 📌 How to Use

1. Open the Live Demo link.
2. Enter a topic.
3. Select the number of questions.
4. Select the difficulty level.
5. Click **Generate MCQs**.
6. Select an answer for each question.
7. Click **Submit Answer** to check the result.
